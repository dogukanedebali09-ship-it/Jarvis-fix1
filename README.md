# JARVIS Android

Gemini Live tabanlı Türkçe sesli yapay zekâ asistanı (Android).

## Özellikler
- Sesli sohbet, konuşurken sözünü kesebilirsin
- Yazılı mesaj
- Kalıcı hafıza
- Uygulama açma, hava durumu, pil/saat
- Google, YouTube ve Spotify arama
- Medya kontrolü, takvim, alarm
- WhatsApp mesajı hazırlama

## Kurulum
1. Actions sekmesinden "Android APK" çalışmasını aç
2. En alttaki **JARVIS-apk** dosyasını indir
3. Zip'ten `app-debug.apk` dosyasını çıkar, telefona kur
4. Uygulamada ⚙ ayarlarından Gemini API anahtarını gir
   (ücretsiz: https://aistudio.google.com/apikey)

## Notlar
- WhatsApp mesajı ve takvim kaydı için son tuşa kullanıcı basar (Android kısıtı).
- Uygulama arka plana geçince mikrofon oturumu kapanır.
